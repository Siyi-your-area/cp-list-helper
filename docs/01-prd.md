**文档版本**：v1  
**创建日期**：2026-06-10  
**产品名称**：CP List 帮手  
**文档维护人**：Siyi

---

## 【需求背景】

### 产品定位
面向同人展会（如 Comicup）参展者的心愿单管理工具。通过上传 CPP 心愿单，自动生成多维度表格，关联场馆地图，并在展会中实时记录开摊、完售、购买等信息，解决信息分散、现场记录困难的痛点。

### 目标用户
- 频繁参加同人展会的参展者/同人爱好者
- 有较多心愿单物品需要采购的用户
- 需要高效规划展会路线的用户

### 核心痛点

**展会前：**
1. 心愿单信息不完整：缺少价格、摊宣、摊位号与地图割裂
2. 无法选择购买数量、记录限购量
3. 无料/有料混在一起，难以区分
4. 信息分散在 CPP、小红书、微博等多平台，需要手动整合

**展会中：**
1. 价格容易忘记
2. 难以进行路径规划
3. 购买信息难以实时记录（已购/已完售/余量等）

## 【需求详情】

### 核心功能

#### 一、展会前 — 自动生成多维度表格

**数据字段：**

| 字段 | 来源 | 可编辑 | 说明 |
|------|------|--------|------|
| 时间 | 自动解析 | ✅ | 展会日期 |
| 场馆 | 自动解析 | ✅ | 展馆名称 |
| 摊位号 | 自动解析 | ✅ | 如 A01、B23 |
| 开摊时间 | 手动填写 | ✅ | 摊主公布的开摊时间 |
| 状态 | 默认"待购买" | ✅ | 待购买/已购买/已售罄 |
| 制品名称 | 自动解析 | ✅ | 周边/本子名称 |
| 作者/社团 | 自动解析 | ✅ | 社团名或作者名 |
| 图片 | 自动解析 | ✅ | 制品预览图 |
| 价格 | 手动填写 | ✅ | 单价 |
| 备注 | 手动填写 | ✅ | 摊宣信息、限购说明等 |
| 购买数量 | 手动填写 | ✅ | 计划购买数量 |
| 限购量 | 手动填写 | ✅ | 摊主设定的限购 |
| 类型 | 手动选择 | ✅ | 有料/无料 |
| 地图位置 | 自动映射 | ✅ | 关联场馆地图坐标 |

**功能点：**
1. **上传心愿单**：支持上传 CPP 导出的表格（Excel/CSV），自动解析并填充字段
2. **表格编辑**：所有字段支持在表格内直接编辑，方便补充小红书、微博看到的摊宣信息
3. **地图映射**：导入场馆地图后，可将摊位号 mapping 到地图具体位置
4. **导出功能**：支持下载/导出表格（Excel 格式）
5. **筛选排序**：按摊位号、状态、类型（有料/无料）筛选；按价格、摊位号排序

#### 二、展会中 — 实时记录与搜索

**功能点：**
1. **摊位搜索**：输入社团名/作者名/摊位号，模糊匹配，显示摊位号和地图上的大概位置
2. **购买记录**：快速记录单价、数量、实付金额、备注（代购信息、付款方式），一键标记"已购买"/"已售罄"
3. **路径规划**（v2）：根据已标记的待购买摊位，推荐最优路线

#### 三、多端支持

- **网页版**：完整的表格编辑和管理功能
- **手机端**：适配移动端，重点支持展会中的快速记录和搜索

### CPP 心愿单原始字段结构（已确认）

通过分析用户提供的 CPP 导出样例（CP32-二期），确认原始字段如下：

| 字段 | 示例 | 说明 |
|------|------|------|
| 社团摊位号 | 贰G18、肆F32 | 包含场馆区域信息（贰、肆代表不同馆） |
| 展品名称 | 【新刊】图奈单性转漫画本 | 制品完整名称 |
| 社团名称 | 大宇宙咩咩牧场 | 社团/作者名 |

**痛点验证：** CPP 导出只有 3 个字段，缺少价格、图片、摊宣、开摊时间、限购量等关键信息，用户需要在多个平台手动补充。

### MVP 版本功能范围（第一版）

| 模块 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| 心愿单管理 | 上传 CPP 表格自动解析 | P0 | 核心功能 |
| 心愿单管理 | 表格展示与编辑 | P0 | 支持所有字段编辑 |
| 心愿单管理 | 导出 Excel | P0 | 方便备份和分享 |
| 摊位搜索 | 模糊搜索摊位号/社团名 | P0 | 展会中快速查找 |
| 购买记录 | 记录单价、数量、状态 | P0 | 实时同步购买情况 |
| 地图功能 | 摊位号与位置关联 | P1 | 可先展示文字位置描述 |
| 多端支持 | 网页版（响应式适配手机） | P0 | 先做网页版，一码多端 |
| 用户系统 | 本地存储 | P0 | MVP 不做账号体系 |

**MVP 砍掉的功能（v2 考虑）：**
- 场馆地图可视化
- 路径规划推荐
- 多设备同步/云存储
- 原生 App（先用 PWA 或响应式网页）

---

### 风险与待确认项

1. **CPP 表格格式**：不同展会导出格式可能有差异，需兼容
2. **场馆地图数据**：场馆地图来源需确认
3. **数据存储**：MVP 用本地存储，换设备数据会丢失，v2 需加入账号体系
4. **摊位号格式**：不同展会摊位号格式不同，需兼容多种格式
