## 一、测试策略

## 二、自动化测试（`scripts/qa-test.mjs`）

### 运行方式

```bash
# 先启动开发服务器
npm run dev

# 另一个终端运行测试
node scripts/qa-test.mjs
```

### 测试覆盖范围

| 编号 | 测试项 | 说明 |
|------|--------|------|
| 1 | 首页加载 | 页面正常渲染 |
| 2 | 页面标题 | 包含 "CP" |
| 3 | 创建按钮 | "创建新展会" 按钮存在 |
| 4 | 空状态提示 | 无展会时显示提示 |
| 5 | 展会创建 | 填写表单并创建成功 |
| 6 | 数据持久化 | localStorage 正确存储 |
| 7 | 空表单验证 | 必填项校验 |
| 8 | 详情页加载 | 展会详情页正确渲染 |
| 9 | 统计卡片 | 统计面板正常显示 |
| 10 | 搜索功能 | 搜索框存在且可交互 |
| 11 | 编辑按钮 | 编辑模式切换 |
| 12 | 上传/导出按钮 | 功能入口存在 |
| 13 | 100 条数据渲染 | 大数据量性能 |

| 15 | 特殊字符处理 | 输入安全 |
| 16 | 多次刷新稳定性 | 数据不丢失 |

### 测试结果输出

- 控制台输出：✅ PASS / ❌ FAIL / ⚠️ WARN
- 文件输出：`test-report.json`（含通过率统计和问题列表）

## 三、手动测试清单

### 3.1 心愿单上传

- [ ] 上传 CP32 一期/二期 Excel，验证解析正确
- [ ] 上传空 Excel，验证容错
- [ ] 上传非 Excel 文件，验证错误提示
- [ ] 验证空摊位号/空社团名的容错处理

### 3.2 CPP 匹配

- [ ] 精确匹配：摊位号 + 展品名完全一致
- [ ] 全角/半角差异匹配
- [ ] 名称包含匹配
- [ ] 作者匹配（名称不一致时）
- [ ] 模糊匹配（相似度 > 60%）
- [ ] 未匹配项显示"未匹配"状态

### 3.3 表格编辑

- [ ] 所有字段可编辑
- [ ] 状态切换（待购买→已购买→已售罄）
- [ ] 优先级设置（首摊/次摊/P1-P3/随缘）
- [ ] 筛选功能（按状态、类型）
- [ ] 排序功能（按摊位号、价格）
- [ ] 分页（100 条/页）

### 3.4 搜索

- [ ] 按摊位号搜索
- [ ] 按制品名搜索
- [ ] 按作者搜索
- [ ] 模糊匹配结果正确

### 3.5 导出

- [ ] 导出 Excel 包含所有字段
- [ ] 文件名带展会名称
- [ ] 导出后文件可正常打开

### 3.6 移动端

- [ ] 表格横向滚动
- [ ] 按钮触摸友好
- [ ] 搜索/筛选 UI 正常
