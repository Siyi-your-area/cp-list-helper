# CP list帮手 UI 设计规范

> 状态：已确认，供桌面端与手机端统一使用

## 1. 字体

全站使用思源黑体同源字体 `Noto Sans SC`，通过 `next/font` 自托管。

| 层级 | 字号 / 行高 | 字重 | 使用场景 |
|---|---|---:|---|
| Display | 32 / 43 | 700 | 空状态或核心宣传标题 |
| H1 | 24 / 34 | 700 | 页面标题 |
| H2 | 20 / 29 | 600 | 模块标题 |
| H3 | 16 / 24 | 600 | 卡片、弹窗标题 |
| Body | 14 / 24 | 400 | 正文、表格和表单 |
| Caption | 12 / 18 | 500 | 时间、计数、标签和辅助说明 |

正文不得使用装饰字体；次要文字也必须保持足够对比度。

## 2. 基础颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| Sand | `#AF9F8C` | 次操作、暖色提醒 |
| Grass | `#7F867B` | 品牌原色、成功状态 |
| Grass Strong | `#5F685D` | 主按钮，搭配白字 |
| Matcha | `#C7C7BB` | 标签、进度和分隔 |
| Dusty Rose | `#D4C8BE` | 待确认、信息强调 |
| Linen | `#E3E4E0` | 浅色辅助背景 |
| Page | `#F8F8F6` | 页面背景 |
| Surface | `#FFFFFF` | 卡片、弹窗、输入框 |
| Ink | `#454A44` | 主要文字 |

不得再使用亮蓝、亮黄或高饱和绿色作为产品主色。

## 3. 按钮

- 高度至少 40px，圆角 12px，文字 14px / 500；
- 主按钮：`Grass Strong` 背景 + 白色文字；
- 次按钮：浅 Dusty Rose 背景 + 深色文字；
- 描边按钮：白色背景 + Matcha/Sand 描边 + 深色文字；
- 危险按钮：浅红背景 + 深红文字；
- 图标固定在文字左侧，纯图标按钮必须提供 `aria-label`。

## 4. 图标

- 产品操作图标统一使用 `@phosphor-icons/react`；
- 默认使用 `regular` 线性风格，不混用 fill、duotone 和 bold；
- 表格内联 16px、按钮 18px、导航 20px、空状态 32px；
- 品牌小熊头是唯一允许使用自定义 SVG 的图标。

## 5. 状态

颜色只能辅助文字，任何状态都必须显示明确文案：

- 待购买/待领取：暖色浅背景；
- 已购买/已领取/已匹配：Matcha/Grass 浅背景；
- 已售罄/错误：低饱和浅红背景；
- 待确认：Dusty Rose 背景；
- 无料/普通信息：Linen 背景。

## 6. 表单、卡片和弹窗

- 输入框高度约 42px，白色背景，聚焦时使用 Grass 细描边；
- 卡片使用白色背景、1px 浅边框，避免厚重阴影；
- 桌面端弹窗居中，手机端复杂表单使用底部抽屉；
- 弹窗主操作放右侧，手机端主操作可占满底部宽度；
- 遮罩使用中性深灰透明色，不使用彩色遮罩。
