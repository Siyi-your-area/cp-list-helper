# CPFZ 手机端「地图找摊」产品草案

状态：已接入 CPFZ 手机清单并部署生产。当前点位覆盖 1–4 馆图中规则排列的摊位排，特殊/断排没有可靠坐标时不显示地图标记，仍保留在清单中。后续仍需按实际数据逐排核对覆盖率。

## 目标和范围

- 仅在 CPFZ list 的手机端提供「清单 / 地图」切换；电脑端保持现状。
- 地图以仓库 `cpfz_map/场地图1馆.png` 至 `场地图4馆.png` 为底图。覆盖当前 list 中的摊位标记，标记写作「壹S25(2)」：场馆、摊位号、该摊位的制品数量。
- 9 馆只展示 `cpfz_map/场地图9馆.png`，不制作摊位点位、不叠加清单标记；显示清楚的「9 馆暂不支持摊位定位」说明。
- 不做导航、路线规划、室内定位，也不改展品匹配、排序、状态或电脑端页面。

## 入口与主流程

1. 在 CPFZ 手机清单页的**一级菜单**提供「清单 / 地图找摊」切换，位置高于统计、搜索和筛选。默认仍为清单，不改变既有用户的打开习惯。清单模式保持原来的统计、搜索和筛选；地图模式不显示统计或搜索，只保留既有「只看未买/取」筛选。
2. 地图页切换壹、贰、叁、肆、玖馆；记住本次访问选中的馆和地图缩放状态。地图可双指缩放和拖动，并有明确的放大、缩小按钮。
3. 初次进入地图模式**只显示地图和标记，不预先展开清单卡片**。只标当前 list 中、能确认坐标且**摊位实际点位处于当前可见地图范围内**的摊位。一个摊位的多件制品只出现一个点标记，数量按筛选后的制品行数计，不按 `quantity` 求和。打开「只看未买/取」后，只计入待购买、已买待取、待领取的制品。切换馆、拖动、缩放或筛选时，立即重新计算可见点位；点位移出视窗，其标签、引线和下方选中摊位卡片都消失。可见范围内没有当前 list 制品时，地图不展示任何标记。
4. 聚合标记和点标记都可点击：聚合标记放大到其覆盖的摊位附近，并拆成可点的摊位标记；点标记也放大、居中到该摊位附近，同时在地图下方直接展示该摊**全部**制品，不再另设「查看全部」。每件卡片最多两行：第一行制品名，第二行作者，不展示价格；优先级与状态置于末尾，样式直接复用手机清单。可快速变更状态，也可一键「本摊完成」；点卡片其他区域打开现有制品详情，保存后回到地图且保留地图位置。
5. 地图点位缺失、摊位号不规范或馆号冲突时，绝不猜位置；这些制品**不在地图模式展示**，也不出现「未定位」分组或入口。它们仍完整保留在清单模式，可照常查看和修改。一期不允许通过点击空白地图新建制品；在地图点位手动新增属于二期。地图遵循手机手势：单指拖动即时移动，双指捏合缩放，以双指中心为缩放锚点；缩放按钮与手势使用同一套坐标变换。

## 标记身份、计数与聚合规则（拟定）

- **先按清单摊位号归组，再做视觉聚合。** 当前 `wish_items.booth_number` 已保存完整摊位号。以「场馆 + 去除空格、统一全角半角后的完整摊位号」为组键；例如清单写「叁H21叁H22」就直接视作一组，展示一个点标记「叁H21叁H22(2)」。不新增 `stallGroupId`，不依据两个编号相邻、摊主名称或作者去推断归并；只写「叁H21」的其他记录也不会自动并进「叁H21叁H22」组。若原始数据写法不一致，仍需用户在清单中修正，不让地图猜测。
- **点标记**：`完整摊位号 + (Y)`，**不加「件」字**。`Y` 是当前 list、当前筛选中该组的不同 `wish_items.id` 数；数量字段 `quantity=3` 仍只算 1 条清单制品。单号示例「贰R24(2)」，多号示例「叁H21叁H22(2)」。
- **聚合标记**：缩小地图时，将当前视窗内标签会碰撞的多个清单摊位组临时合并为 `馆名 + 摊位号范围 + X摊 + Y件 · 点此放大`。`X` 是不同完整摊位号组键数，`Y` 是组内不同制品 ID 数。例如 R23、R24、R25、R26 四组共有 7 条制品，显示「贰R23–R26 · 4摊 · 7件 · 点此放大」。写成「叁H21叁H22」的一组对 `X` 只贡献 1。
- **坐标映射**：静态点位资料只需每个已核验单号的 `hall + boothCode + x/y`。多号组保留原字符串作为展示名与组键，仅在定位时读取其中第一个完整摊位号的已核验坐标作为锚点；不为多个号建立映射关系或求中心点。无法从同馆已核验点位确定锚点的组，不在地图展示，仍留在清单模式。
- **计算位置**：是否相邻、是否碰撞、显示聚合还是点标记取决于手机实际宽度、视窗和缩放比例，在前端每次拖动/缩放/筛选后即时计算，不把某一缩放级别的聚合结果写进数据库。先裁剪视窗外锚点，再在同馆内按屏幕像素检测标签碰撞并稳定分组；不跨馆聚合、不把视窗外摊位计入。必要时限制单组屏幕范围，避免一串相邻摊位被连成横跨整馆的巨型聚合。
- **最小数据流**：已核验点位可先随地图版本发布为静态数据，不必增加用户数据库表。清单仍沿用现有 `wish_items`；整理层输出 `{hall, boothLabel, x, y, itemIds}`，其中 `boothLabel` 是完整摊位号，`itemIds` 去重。前端用当前状态与「只看未买/取」计算每摊 `Y`，再依当前视窗计算聚合的 `X/Y`。离线时也从本机清单重算，不依赖服务器聚合请求。
- **可拆开性**：点击聚合组时，以包含的原始摊位点求边界，放大至标签能分别显示；若已到最大缩放，改用互不交叉的直角引线排开标签，不能让点击后仍是同一个无变化聚合。点击单摊标记则放大并居中该摊位，即使已经放大，也要保持该摊位可见并打开制品预览。

## 相邻摊位与缩放

- 全馆视图优先展示可读性：相邻标记可能聚合成「贰R23–R26 · 4摊 · 7件 · 点此放大」。点聚合标记自动放大至能分别显示每个摊位。
- 放大后每个摊位都有独立的点位与可点击标记，如「贰R23(1)」「贰R24(2)」。优先让标签贴近点位；不得不外移时，按地图上摊位的物理顺序排布，使用短横线或直角折线，不用相互交叉的斜线。标签不能覆盖其他标签，触控区域至少 44×44 CSS px。
- 缩放只改变显示方式，不合并摊位数据；地图标记按当前可见范围和「只看未买/取」即时计算，清单统计仍按原有口径计算。
- 场馆切换复用清单里「全部 / 壹 / 贰 …」的紧凑分段样式，保持 40px 左右的点击高度，不铺满一整行宽矩形。点标记参考现有优先级标签：视觉上是贴合文字的浅色细边短标签，内部留白收紧；可点击区域仍至少 44×44px。聚合标记可保留双行说明，但同样避免多余的上下留白。颜色、字体和边框以 `docs/10-ui-design-system.md` 为准。

## 点位资料的制作与校验

底图含馆号、排字母、少数编号锚点和连续的小格，**并非每个摊位都印有完整编号**。因此单次 OCR 无法可靠得到所有摊位坐标，不能把识别到的文字直接当点位。正式上线前需完成以下流程：

1. 按馆把原图切成高清区域，识别排字母、编号起止和中间锚点；保留原图坐标及 OCR 置信度。
2. 对每排检测格线/摊位小格，按图上实际的编号方向逐格推算，不根据其他馆的排法套用。特殊区、断排、双面排和独立小摊单独标注。
3. 形成 `event=CPFZ, hall, booth, x, y` 点位表，`x/y` 为相对原图宽高的归一化坐标；同一「馆 + 摊位号」只能有一个确定点位。地图资源和点位表使用同一个版本号，避免换图后坐标错位。
4. 对 1–4 馆逐排核验首、中、末编号及方向；对每个 OCR 不确定或几何异常的位置人工核对。检查重复编号、越界坐标和明显落在通道/装饰区的点。未经核验的点位不进入正式标记表。
5. 用真实 CPFZ list 的摊位号与点位表做覆盖率检查。无坐标的记录列出清单、原因和数量；若影响上线体验，补齐后再发布。9 馆不计入定位覆盖率。

当前已核对五张原始图片尺寸：1 馆 5669×2972、2 馆 5677×2972、3 馆 5677×2972、4 馆 5669×2972、9 馆 2972×5677。正式页面使用原始清晰 PNG，按各馆真实宽高比放置标记，缩放时图片与点位同步变换。1–4 馆规则摊位排已依深色矩形中心校准，考虑每五号标注方向、个别星标覆盖的矩形；叁馆 E 排为 24 个摊位，叁馆下半区只有 I–L 排，肆馆上半区只有 A–F 排、下半区只有 G–N 排。没有规则小格的区域不推断坐标。原型里的示例制品仅用于验证布局与操作；正式摊位点以原图逐格校验。原型使用贰馆相邻 R 排演示；S23–S26 遵循相同规则，实际以 CPFZ 地图上的排号为准。

## 保存与弱网

- 地图只是现有清单的另一种查看方式。线上状态变更沿用现有保存流程；处于手动离线模式时沿用本机保存与恢复同步，不引入第二套队列。
- 地图图片和点位表须在用户有网准备 list 时一并缓存，现场离线状态可查看已准备的地图。原图约 2–4 MB/馆，应按需加载当前馆；离线准备时明确告知要缓存哪些馆及大小。没有提前缓存时明确提示「地图尚未准备」，不能假装可用。
- 快速改状态需要继续展示既有的「正在保存 / 已保存到云端 / 仅保存在本机 / 同步失败」，不能因为地图卡片关闭而丢失结果反馈。

## 验收重点

| 场景 | 预期 |
| --- | --- |
| 清单 / 地图切换 | 同一 list、筛选条件和状态，不刷新或丢失未保存编辑 |
| 一级菜单 | 地图模式无统计和搜索，仅有「只看未买/取」；清单模式保留原有内容 |
| 壹至肆馆切换 | 对应底图及当前 list 的摊位，位置与原图一致 |
| 9 馆 | 只显示整图和不定位说明，无虚假标记 |
| 相邻四个摊位 | 全馆可点范围标记；放大后四个完整标签可分别点选 |
| 同摊多件制品 | 标记数字等于该摊制品行数；卡片可快速改状态和进入详情 |
| 清单写多号摊位 | 「叁H21叁H22」作为完整组键只出现一个点标记，不自动合并单号记录 |
| 点标记文案与尺寸 | 显示「贰R24(2)」而非「贰R24(2)件」；紧凑标签、点击热区至少 44px |
| 初次进入地图 | 不显示任何摊位制品卡片；点聚合/点标记都能放大 |
| 点标记制品预览 | 直接展示该摊全部制品；第二行只显示作者，不显示价格 |
| 地图手势 | 单指拖动即时移动，双指以手势中心缩放，按钮缩放仍正常 |
| 未知摊位 | 地图模式完全不展示；切回清单仍可查看与修改，其他已定位摊位不受影响 |
| 地图画质 | 放大后清晰度来自原始 PNG 或无损图块；不把缩略图拉大作高清图 |
| 相邻标签 | 横线或直角折线互不交叉，摊位点和标签可一一对应 |
| 拖动到空白范围 | 无制品点位的视窗没有标记、引线和选中卡片；拖回原处才重新出现 |
| 地图筛选 | 打开「只看未买/取」后，已购买、已领取、已售罄从标记数量和卡片中排除；无剩余制品的摊位不再标记 |
| 离线切换与同步 | 地图可见，状态变更保存在本机，恢复网络后沿用原有同步提示 |
| 375 / 390 px 手机宽度 | 地图、标记、卡片不横向溢出；主要触控目标不小于 44 px |

## 已确认的产品选择

- 地图标记为「馆 + 摊位号 + 当前 list 的制品件数」。
- 只标当前 list，不展示全展会所有摊位标记。
- 只展示当前地图视窗内的标记；地图模式不展示统计和搜索。
- 相邻摊位在低缩放可聚合；点聚合自动放大逐个显示。
- 9 馆仅展示底图，不进行点位定位。
